# 电商设计师 AI 主图与品牌海报：策划先行全流程 SOP

## TL;DR

- **2026 设计师分水岭**：AI 不取代设计师，但 **会用 AI 做全流程策划** 的设计师，会甩开只会用 AI 做执行的人。
- **流程反转**：旧链路「先拍再修再排版靠感觉」→ 新链路 **商业分析 → 视觉策划 → AI 精修/生图 → PS 文案收尾**。
- **主图六步（充电宝案例）**：商业判断 → 3–5 视觉方案+提示词 → 产品精修 → 参考图反推场景词 → 场景图生成 → PS 排版。
- **海报六步（黄金吊坠案例）**：品牌/产品分析 → 人群与市场 → AI 出 3–5 方案 → **AI 写提示词**（非让 AI 猜）→ 喂图生图 → PS 提质感。
- **主图转化逻辑**：吸引点击（产品+核心卖点）→ 建立信任（卖点/品牌）→ 促成下单（优惠/保障）。
- **提示词公式**：场景 + 产品 + 细节 + 光影 + 风格 + 技术参数；**GIGO**——直接扔产品图要「高级感」易出塑料感/老气模板。
- 与 [一人店 SOP](2026-06-09-ai-ecommerce-solo-store-playbook.md) 对照：彼文偏 **运营测款快出图**，本文偏 **设计师级商业策划+质感把控**。

## 适用场景

**何时用：**

- 电商/品牌设计师接入 AI，需要 **可复制的策划→生图→PS** 工序，而非单点「文生图」。
- 主图 CTR 低、海报 **塑料感/风格跑偏**（红底金框、龙凤模板），需先 **商业分析再出视觉**。
- 团队规范：要求 **AI 做分析与草稿，设计师做判断与终稿**。

**何时不用：**

- 零基础卖家只要白底/场景测款 Prompt——见 [一人店 SOP](2026-06-09-ai-ecommerce-solo-store-playbook.md)。
- 平台级 AI 试穿/意图购产品能力——见 [618 平台格局](2026-06-09-618-ai-ecommerce-platform-landscape.md)。
- 作者引流的「AI 超级工作流」知识库商品——本文为 **方法论提炼**，非该付费课 SSOT。

## 知识要点

### 1. 核心观念：策划 > 执行

| 角色 | 职责 |
|------|------|
| **AI** | 市场调研、竞品拆解、卖点提炼、视觉方案草稿、提示词撰写、精修/场景合成 |
| **设计师** | 商业判断、方案选择、参数微调、质感与光影终修、文案排版、品牌调性守门 |

**竞争力**：工具普及后，壁垒在 **审美 + 商业思路**，而非会不会点生图。

**反面案例**：未分析品牌就把黄金产品图扔给 AI → 易出红底金框、龙凤呈祥等 **与非遗手工调性不符** 的模板感。

### 2. 主图全流程（7 步 · 充电宝案例）

**原则**：拿到产品 **不要先开 PS/AI 开干**，先用 AI 做 **商业角度判断**，确保主图有转化力。

1. **商业分析**：人群、竞品、产品、核心卖点（可用 LLM/工作流辅助）
2. **视觉策划**：输出 **3–5 套** 视觉方向 + 可生图的 **设计提示词**（可跨平台参考）
3. **AI 精修产品**：实拍图 + 精修提示词 → 产品抠图/细节保留；文中用 **Nano Banana** 模型，设计师 PS 微调瑕疵
4. **反推场景提示词**：按策划方案找 **参考图** → AI **反推** 场景描述 → 与产品描述 **合并** 为场景 Prompt
5. **生成场景图**：精修产品 + 参考图 + Prompt → 迭代模型/参数，边生边选
6. **PS 后期**：场景优化 + 按商业分析整理 **卖点文案** → 排版
7. **案例复盘**：完整充电宝主图（作者展示成稿）

### 3. 品牌海报全流程（6 步 · 黄金吊坠案例）

1. **卖什么再想怎么卖**：AI 分析品牌——例：非「卖黄金」而是 **非遗手工传承**；工艺：双层镂空花丝、立体浮雕牡丹；明确配色与素材边界
2. **谁在买单**：市场与用户——例：非遗扶持、高溢价稀缺；定位 **古法黄金与顶级收藏之间的空白**；**30–55 岁高价值女性**，重文化/工艺/身份
3. **AI 出 3–5 视觉方案**：如尊贵典藏礼盒、东方古韵香道、匠心微距特写
4. **AI 写提示词（关键）**：勿只写「图一产品+图二背景」；流程为 **参考图反推 → AI 生成 Prompt → 人工微调**
5. **喂图生成**：产品图 + 参考图 + Prompt；**不指望一次完美**，设计师控质量
6. **PS 提档次**：曲线/锐化/滤镜优化产品与光影；排 **LOGO + 文案**

### 4. 主图营销三层（转化结构）

```
吸引点击（产品视觉 + 核心卖点）
    ↓
建立信任（主要卖点、品牌信息）
    ↓
促成下单（优惠、保障信息）
```

文案与视觉须 **同源于前期商业分析**，避免画面精美但卖点不清。

### 5. 提示词与质感

**万能公式**：

```text
场景 + 产品 + 细节 + 光影 + 风格 + 技术参数
```

**反推工作流**：找符合策划方向的 **参考图** → 让 AI 描述场景 → 与 **产品精修描述** 合并 → 再送入生图模型。

**塑料感成因（归纳）**：跳过品牌/人群分析、Prompt 过短、缺光影与材质参数、无 PS 终修。

**与一人店主图 Prompt 的关系**：[一人店 SOP](2026-06-09-ai-ecommerce-solo-store-playbook.md) 提供 **白底/场景/测款** 轻量模板；本文在 **策划层 + 反推 + 精修** 上更深，面向职业设计师。

## 代码 / 命令

### 商业分析 Prompt（主图/海报通用 · 可接 DeepSeek 等 LLM）

```text
我是电商设计师，产品为【产品名/品类】，品牌调性为【简述】。
请帮我完成：
1. 目标人群与购买动机
2. 竞品主图/海报常见套路与差异化机会
3. 3 条核心卖点（可视觉化）
4. 主图/海报应避免的视觉雷区
输出简洁，便于下一步视觉策划。
```

### 视觉策划 Prompt

```text
基于以下商业分析：
【粘贴上一步结果】

请给出 3–5 套视觉策划方案，每套包含：
- 方案名称与适用平台（淘宝/京东/小红书等）
- 画面构图与色调
- 可直接用于 AI 生图的英文或中文提示词草案
```

### 参考图反推场景 Prompt

```text
我上传的是参考风格图。请反推一段场景描述 Prompt，包含：
场景环境、光线方向、色调、氛围、摄影机位。
不要包含具体品牌名。输出一段可与我产品描述合并的 Prompt。
```

### 场景生图 Prompt 骨架（合并产品后）

```text
【场景反推描述】，
产品：【精修后的产品类型与材质细节】，
【细节：纹理/反光/摆放方式】，
【光影：柔光/侧光/轮廓光等】，
【风格：商业摄影/极简/东方禅意等】，
【技术参数：8k、浅景深、真实投影等】
```

### PS 收尾检查清单

- 产品边缘与场景光影是否一致
- 曲线/锐化是否过度（黄金/金属类易假）
- 卖点层级：点击 → 信任 → 下单信息是否可读
- 品牌 LOGO、合规字号与平台主图规范

| LLM / 「AI 超级工作流」 | 商业分析、视觉策划、提示词撰写（作者使用自定义工作流，无公开链接） |

## 注意事项

- 来源为 **设计师公众号教程**，含自推知识库引流句，入库已剔除「唯一一套」等营销表述。
- **Nano Banana / AI 超级工作流** 非本仓库验证工具，落地时替换为团队在用的 LLM + 生图模型即可。
- 黄金、非遗等 **高信任品类** 仍须符合平台素材与广告合规；AI 图需关注 **标注与真实性** 要求。
- 不要跳过 **人群与品牌分析**——这是避免模板感与塑料感的最大杠杆。
- AI 生成图 **不可替代** 设计师对品牌调性与 CTR 结构的判断；建议保留 A/B 测主图习惯（见一人店一周模型）。
